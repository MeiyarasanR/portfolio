Selected work

PRJ / 01 Repo

RISC-V RV32I Single-Stage Processor Design & Verification

Designed and implemented a 32-bit single-stage RISC-V RV32I processor in Verilog with instruction fetch, control unit, ALU, register file, immediate generator, PC, and data-memory interface. Built a layered SystemVerilog verification environment with generator, driver, monitor, scoreboard, functional coverage, and assertions. Verified arithmetic, logical, load/store, and branch instructions using self-checking testbenches and waveform analysis.

VerilogXilinx VivadoQuestaSim
PRJ / 02 Repo

UART-Controlled Hardware Accelerator SoC on ZedBoard

Designed and implemented a MicroBlaze-V based FPGA SoC on the ZedBoard by integrating Xilinx IP cores and custom AXI4-Lite peripherals — including a hardware multiplier, LED controller, and timer IP. Developed embedded C applications in Vitis to drive the hardware through memory-mapped AXI registers, and validated the full system on FPGA through UART communication.

Xilinx VivadoVitisMicroBlaze-VAXI4-Lite
PRJ / 03 Repo

SPI Protocol Functional Verification

Developed a layered SystemVerilog verification environment for an SPI Master-Slave communication system, with transaction, generator, driver, monitor, scoreboard, and environment components. Verified 12-bit SPI data transmission using constrained-random stimulus, automated scoreboard checking, and waveform analysis to validate protocol functionality and data integrity.

SystemVerilogEDA PlaygroundQuestaSim

GCD Processor RTL Verification

Designed and implemented a Greatest Common Divisor processor in Verilog using separate datapath and FSM-based controller modules following RTL design principles. Verified functionality through directed Verilog testbenches, waveform analysis, and simulation debugging — validating state transitions, control logic, and arithmetic operations across multiple test cases.

PRJ / 05 — RESEARCH

Low-Power 1D-CNN Hardware Accelerator for ECG Arrhythmia Detection

Designed a low-power FPGA-based 1D-CNN hardware accelerator using approximate multipliers and operand isolation techniques, cutting dynamic power by 96.5%. Achieved 98.5% classification accuracy on the MIT-BIH Arrhythmia Database while consuming only 142 mW total power at 100 MHz, using 302 LUTs and 336 flip-flops with no DSPs or BRAMs. Improved signal quality with a 4-tap FIR filter and adaptive thresholding, validated end-to-end through MATLAB–Vivado co-simulation.

Xilinx VivadoMATLABApproximate ComputingZynq XC7Z020
